R package · Time-to-event simulation

simtte

An R package that extends mrgsolve to simulate time-to-event data, from Weibull and M-spline baseline hazards to hazards driven by a PK/PD model.

CRAN ↗ GitHub ↗

Install

The CRAN release is 1.0.2. The examples below use the development version, 1.1.0, which adds sim_tte_ode(), tte_model() and the censoring and visit-schedule tools. 

install.packages("simtte")                     # CRAN release, 1.0.2
remotes::install_github("csetraynor/simtte")   # development version, 1.1.0

Examples

Getting started

Weibull and M-spline baseline hazards with sim_tte(), using inverse transform sampling. The code is shown but not run.

Joint PK/PD and time-to-event simulation

A hazard driven by a PK/PD model, with survival solved as one more ODE compartment, and coxph() recovering the treatment effect.

Censoring and realistic assessment schedules

Right and interval censoring, plus visit schedules with jitter, missed visits and outcome-dependent assessments, added to any simulated cohort.

Simulating from a Cox model

Proportional-hazards data from a baseline you choose or one estimated from survival::lung, with checks that coxph() recovers the effect.
