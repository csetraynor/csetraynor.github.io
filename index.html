About

I'm a quantitative scientist grounded in clinical pharmacology and pharmacometrics. I build Bayesian and mechanistic models for questions where the data are sparse or noisy and a decision still has to be made: which dose to test, how a trial will behave before it runs, or whether a survival signal holds up.

Most of that work combines nonlinear mixed-effects models, exposure-response and time-to-event analysis, multistate and joint models, and simulation. I fit them in Stan, Torsten, NONMEM and R, and I release the reusable parts as open-source R packages so others can check and extend them.

I'm now working more on probabilistic machine learning inside pharmacometric models, and exploring projection predictive variable selection for survival models with projpred. The same computational habits carry over to quantitative problems outside drug development, and to AI-assisted software development.

Selected work

simtte

Examples · CRAN ↗ · GitHub ↗

R package that extends mrgsolve for time-to-event simulation, with Weibull and M-spline baseline hazards, for trial design and endpoint simulation.

StanFlowR

GitHub ↗

R package that orchestrates Stan and Torsten model workflows through the native CmdStan CLI, so Bayesian pharmacometric models can run on HPC and cloud compute without cmdstanr or rstan.

erSCM

GitHub ↗

R package for exposure-response analysis with stepwise covariate modelling. It automates common exposure-response steps and produces report-ready outputs. In development.

I've also contributed to Torsten, extending it for multistate models and simplifying its user guide. simtte builds on mrgsolve.
