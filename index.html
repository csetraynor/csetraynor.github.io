About

I'm a quantitative scientist working on Bayesian modelling and model-informed decision-making in complex biological systems. Over the past several years I've built predictive models supporting clinical development, dose optimisation, translational medicine, and regulatory submissions, mostly in oncology.

My work combines Bayesian inference, nonlinear mixed-effects modelling, simulation, and statistical computing to make decisions under uncertainty more rigorous. The aim is to turn noisy clinical and biological data into evidence that holds up under scrutiny.

My interests are increasingly moving beyond drug development into probabilistic machine learning and quantitative research more broadly. I'm applying the same computational habits to problems outside pharma, including AI-assisted software development.

Selected work

simtte

GitHub ↗

R package for simulating bespoke time-to-event data (Weibull and spline hazards), for trial design and endpoint simulation.

StanFlowR

GitHub ↗

R package that orchestrates Stan and Torsten model workflows through the native CmdStan CLI, so Bayesian pharmacometric models can run on HPC and cloud compute without cmdstanr or rstan.

gcsf-neutropenia-kpd-model

GitHub ↗

Bayesian kinetic-pharmacodynamic Stan/Torsten models of neutrophil dynamics under docetaxel chemotherapy, with and without G-CSF support, presented at PAGE 2026.

Bayes-Joint-Model-ctDNA-PFS

GitHub ↗

Stan/mrgsolve code for the joint longitudinal–survival model behind a 2024 Clinical Pharmacology & Therapeutics paper predicting disease progression from ctDNA in EGFR-mutant NSCLC.

miml-synthetic

GitHub ↗

Code for a comparative study of missing-data imputation methods (predictive mean matching, EM, random forests, GANs, tabular networks) on real-world biomarker data.

I also contribute to open-source pharmacometrics tools, including forks of Torsten, mrgsolve, and projpred.
